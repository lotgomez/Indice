## 🎮 Guía de Uso / Controles (Modelos 3D y Supersplat)

<ul>
  <li><b>Moverse (como en un juego):</b> Utiliza las teclas <b>W, A, S, D</b> para avanzar, retroceder y desplazarte hacia los lados.</li>
  <li><b>Rotar la vista:</b> Mantén presionado el <b>clic izquierdo del mouse</b> y arrastra para girar la cámara hacia donde quieras mirar.</li>
  <li><b>Desplazarse (Pan):</b> Mantén presionado el <b>clic derecho</b> (o la rueda del mouse) y arrastra para moverte libremente de arriba a abajo o de un lado a otro.</li>
  <li><b>Zoom:</b> Gira la <b>ruedita del mouse</b> para acercarte o alejarte del modelo.</li>
</ul>
